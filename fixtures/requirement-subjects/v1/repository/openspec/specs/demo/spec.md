# Demo Specification

## Requirements

### Requirement: RQS-002 Second requirement

The report MUST retain the second current requirement.

#### Scenario: Second requirement remains current

- **GIVEN** the second standing requirement
- **WHEN** static analysis runs
- **THEN** the report exposes its current subject

### Requirement: RQS-001 First requirement

The report MUST retain the first current requirement.

#### Scenario: First requirement remains current

- **GIVEN** the first standing requirement
- **WHEN** static analysis runs
- **THEN** the report exposes its current subject
