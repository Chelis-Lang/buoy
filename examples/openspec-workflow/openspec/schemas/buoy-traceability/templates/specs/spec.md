## ADDED Requirements

### Requirement: DEMO-001 Example title

The system MUST state one normative behavior.

#### Scenario: Positive - accepted behavior
- **GIVEN** valid saved repository inputs
- **WHEN** the operation runs
- **THEN** the required result occurs

#### Scenario: Negative - rejected behavior
- **GIVEN** invalid saved repository inputs
- **WHEN** the operation runs
- **THEN** the operation fails with a stable diagnostic
